# Security notes

This preview reads local raster images and project JSON but has no server-side
application or authentication. Do not put private plans into public GitHub issues.
Use the repository's private vulnerability reporting channel when enabled;
otherwise contact its owner privately before disclosing an exploitable issue.

Reports should include the release/commit, browser version, minimal synthetic
reproduction file, expected behavior and observed behavior. Do not include
credentials or real residential plans. No support window or response SLA is
promised for this preview.
