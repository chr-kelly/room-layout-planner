# Synthetic fixtures

`living-working-4x3.json` is a fully editable 4 × 3 metre clear-inside example.
It contains four walls, four furniture blocks and one distance annotation.
It is not derived from a private home or a real measurement.

`calibration-800x600.png` is an original synthetic image. For a deterministic
calibration, use image points (100, 100) and (500, 100) and enter 4 metres.
Then a 200-pixel distance on the same image corresponds to 2 metres.
Human clicking introduces selection error; these pixel coordinates define the
fixture, not a claim about field measurement accuracy.
