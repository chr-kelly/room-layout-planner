# 六语言交互增量

延用现有编辑器布局、颜色、字体和三栏/手机底部面板。本次以实际现有界面为视觉基线，不重做产品页面。基线：[2D](../assets/readme/editor-2d.jpg)、[3D](../assets/readme/editor-3d.jpg)。本环境没有 Claude Design quickstart 或画布工具，未生成或声称交付 Design 原型；改动后的电脑/手机截图用于实际验收。

## 语言入口

桌面将一个紧凑语言选择放到页头右侧，标签使用 English / 繁體中文 / 日本語 / Deutsch / Français / Español。手机将语言选择置于品牌同行，现有保存状态和文件操作保持可访问。原生 select 支持键盘和屏幕阅读器；可交互尺寸至少 44px。

欢迎弹窗同时提供语言和单位选择。初次访问默认英语，并按浏览器语言给出一个可选建议；记住用户主动选定的语言。明确语言路径优先于保存的偏好；根路径首次访问时可恢复用户主动偏好，并更新为相应语言地址。所有视角与文件操作继续用原有位置。

## 状态

空白：本地化欢迎、单位、空画布与对象提示。加载：加载语言/3D 时保留当前方案，菜单暂不可重复提交。出错：加载失败保留原语言，显示原语言的可操作提示；保存或文件校验失败显示对应本地化说明。成功：就地更新文字、画布与地址，当前方案、历史和表单值保留。

## 不中断工作

语言切换只更新文本、属性和渲染器，不能运行 replaceProject、welcome 重建、history.clear 或改变单位。当前属性/弹窗输入不重建，输入框内用户值不翻译。系统默认名称字段只在没有草稿时更新其占位显示，提交未改名时仍保留系统标记。

墙与测量使用稳定 ID 和本地化类别名；预设标签有显式 nameKey，用户改名移除该标记。旧 JSON 没有标记时保留所有原始名字。用户输入文本始终通过 textContent，不能作为 HTML 解析。

## 尺寸与布局

展示数字按 locale 格式；编辑数字使用浏览器可接受的小数输入及清晰单位。不因语言自动改变单位。按钮用简短自然用语，较长说明保留在原帮助和属性位置。画布依据实际文字宽度裁切标签；PNG 采用当前语言，名称保留用户原文。
